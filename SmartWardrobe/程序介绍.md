# SmartWardrobe 程序介绍

## 项目概述

本程序是基于 STM32F407VET6 的智能衣柜运动控制固件。工程使用 STM32CubeMX 生成底层外设初始化代码，使用 Keil MDK 工程 `SmartWardrobeCode.uvprojx` 编译，业务逻辑集中在 `APP` 目录中。

当前固件主要功能包括：

- 5 路步进电机控制：连续运行、停止、急停、加减速、定步数运动、往返运动。
- M5 作为磁铁组件旋转步进电机通道，不使用 EC5 编码器，仅保留手动控制。
- CN5的EC5_A/EC5_B复用为UART4第二测距接口，与USART1现有测距模块独立运行。
- EC1~EC4 编码器状态读取与清零，映射为 EC1=M1、EC2=M2、EC3=M3、EC4=M4。
- M2 通过 UART2/RS485 读取 BRT38-R0M1024-RT1 绝对值编码器，支持按指定角度运动，并在上电后自动回到已校准零点。
- 三轴坐标控制与限位参数管理。
- M3 开环旋转角度记录与旋转限位。
- 串口文本命令控制。
- 心跳输出与速度曲线输出。
- EX_KEY 行程开关检测。
- M1、M3、M4 回到行程开关位置的 HOME 功能；M2 当前不参与总初始化。

## 硬件映射

### 电机

程序支持 `M1` 到 `M5` 五个目标通道，均使用电机控制命令；其中 `M5` 用作磁铁组件手动旋转步进电机。串口命令中的 `M1`、`M2`、`M3`、`M4`、`M5` 对应程序内部通道。

三轴映射：

| 轴 | 电机 |
|---|---|
| X | M1 |
| Y | M3 |
| Z | M4 |

### EX_KEY 行程开关

EX_KEY 使用低电平表示被遮挡或触发。

| 名称 | 引脚 | 用途 |
|---|---|---|
| `EX_KEY1` | `PC0` | M1 HOME 到位检测 |
| `EX_KEY2` | `PC1` | M2 HOME 到位检测 |
| `EX_KEY3` | `PC2` | M3 HOME 到位检测 |
| `EX_KEY4` | `PC3` | M4 HOME 到位检测 |

## 编码器映射

| 编码器 | 对应电机 | 说明 |
|---|---|---|
| EC1 | M1 | 查询和清零 M1 编码器 |
| EC2 | M2 | 查询和清零 M2 编码器 |
| EC3 | M3 | 查询和清零 M3 编码器 |
| EC4 | M4 | 查询和清零 M4 编码器；M4 闭环运动使用该编码器 |
| EC5 | 编码器停用 | CN5信号脚复用为UART4第二测距模块，不参与编码器闭环 |

常用命令：

```text
EC1 STATUS
EC2 STATUS
EC3 STATUS
EC4 STATUS
EC4 CLR
M1 ENC_MOVE DIR=CW RPM=20 CNT=1440
M3 ENC_MOVE DIR=CW RPM=20 CNT=1440
M4 ENC_MOVE DIR=CW RPM=20 CNT=1440
AXIS ENC_MOVE X=720 Y=720 Z=720 RPM=30 TOL=36
AXIS PLACE_CLOTH RPM=10 TOL=6 SLOT=1
AXIS TAKE_CLOTH RPM=10 TOL=6 SLOT=1
```

`M1/M3/M4 ENC_MOVE` 中的 `CNT` 是对应 EC1/EC3/EC4 编码器计数，不是步进电机脉冲，可用于到位判断、方向校验和卡滞检测。`AXIS ENC_MOVE` 使用绝对编码器计数闭环移动三轴：`X=EC1`、`Y=EC3`、`Z=EC4`。
Z/M4实机方向为CCW向上、CW向下；顶部EX_KEY4定义为Z=0，CW向下时Z和EC4计数增加。非回零过程中CCW向上触发EX_KEY4会立即急停，但不会自动清零。
编码器闭环调速当前为 `Kp=0.04, Ki=0.12, Kd=0.0002, I_LIMIT=120, RPM_MIN=20`。若编码器连续 `250ms` 无计数变化，固件会先进入脱困提速，保持 `BOOST_RPM=45`；若到 `1200ms` 仍无计数变化才报 `ERR 206 Mx_ENC_STALL`。失速日志会带 `LAST/RPM/STILL/BOOST/MODE/DIR/STEP`，用于判断最近计数、闭环输出速度、无计数变化时长、是否已进入脱困提速、电机模式、方向和累计 STEP 脉冲数。M1/M3/M4 的方向保护允许 `20 count` 内的小反向抖动，超过后连续 `3` 次或累计 `60 count` 才报 `ENC_WRONG_DIR`；单次 `>=80 count` 仍立即急停。
`SLOT=N` 表示扫描遇到的第 N 块完整定位板。JH-AI-1811 通过 USART1 以 `9600 8N1` 和 Modbus RTU 询问模式返回距离；取衣和放衣统一使用 `200~250mm`、`CONF>=70`、连续3帧且峰峰值不超过8mm的板面候选规则，完整退出且宽度在1000~2200计数内才计为有效板。两种流程都先闭环到`EC1=8860`，清空旧样本并等待2帧新响应后直接以75RPM扫描，进入板面后降至50RPM；目标板完整退出后均不回板中心。
`AXIS PLACE_CLOTH SLOT=N`先执行`ALL HOME`、M2 CW650和`EC4=10000`，随后使用CN5第二测距的三帧稳定中值与两点标定公式计算动态EC1目标。X到达动态目标后依次执行`EC3=1381`、`EC4=12552`、电磁铁ON等待2秒、M4 CCW上抬650电机步、`EC1=1000`、Y归零、`EC4=3263`、M2 CW4000和`EC1=8860`。第一测距扫描到目标板完整退出后执行X左1125、Z下1500、Y前1250、M2 CCW4000、电磁铁OFF等待2秒、Z上150、Y归零及M2 CW1000；最后执行`ALL HOME`，M2以25RPM回`RAW=1008`后上报成功。
`AXIS TAKE_CLOTH SLOT=N`执行`ALL HOME`、M2 CW650、`EC4=3263`、M2 CW1500及`EC1=8860`并扫描。目标板完整退出后依次执行X左1760、Z下1200、Y前1350、M2 CCW1500、Z下670、电磁铁ON等待2秒、Z上520、Y前150和M2 CW1500；随后Y通过EX_KEY3归零、M2 CCW5500、`EC1=1000`、M2 CW4000、`EC4=12552`、`EC3=1470`、`EC1=3200`、电磁铁OFF等待2秒、`EC4=10000`和`ALL HOME`，最后M2以25RPM回`RAW=1008`后上报成功。
取衣激光故障处理遵循“先停机、后生成诊断日志”：进入 204 故障路径会先急停相关电机并取消任务，再读取通信计数和输出串口文本。启动栈已由 1KB 调整为 4KB，较大的故障诊断缓冲区放在静态存储区；若仍发生 HardFault，异常处理会直接关闭 M1~M5 的 STEP 定时器输出和低有效驱动使能，避免电机保持故障前的最后速度。
日常对光使用 `LASER STATUS`，仅显示最新原始 `DIST/CONF`、通信在线、距离有效、板面有效和状态；完整累计计数器改由 `LASER DIAG` 输出。短状态中的 `PLATE=1` 只代表当前单帧满足板面候选条件，不代表完整板面的进入、退出和宽度校验已经完成；手动 M1 命令不会因此自动停车或进入取衣流程。`COMM=0` 或 `VALID=0` 时显示距离只作为最后缓存值。

CN5第二测距模块使用`UART4 PA0/PA1`、`9600 8N1`和独立的Modbus轮询状态机。使用`LASER2 STATUS`查看距离与在线状态，使用`LASER2 DIAG`查看完整错误计数。第二测距只接入放衣前动态EC1计算，不参与取衣、第一测距定位板扫描或ESP32主动上报。

第二测距动态EC1采用两点标定：`K=(D_B-D_A)/(EC_B-EC_A)`，`EC1目标=EC_A+(D-D_A)/K`。标定参数集中在`cmd_dispatch.c`的`PLACE_LASER2_CAL_*`宏中。当前`PLACE_LASER2_CALIBRATION_VALID=0`，未标定时放衣会在`EC4=10000`后的动态X步骤安全停止，不会吸合电磁铁；实测两组距离和EC1后填写参数并把开关改为`1U`。

串口助手标定可执行`DEBUG ON`、`LASER2 STREAM ON`，固件每200ms输出一次`LASER2 DATA DIST/CONF/COMM/VALID/ONLINE/SEQ`。连续输出默认关闭，并且只在文本调试模式发送，避免混入ESP32二进制协议；用完发送`LASER2 STREAM OFF`和`DEBUG OFF`。

### M5 磁铁组件旋转步进电机

M5 使用普通步进脉冲/方向/使能控制磁铁组件角度，本次自动取放衣流程不驱动M5：

```text
STEP: PB14/TIM12_CH1
DIR: PD0
EN: PB15，低电平有效
```

常用命令：

```text
M5 MOVE DIR=CW RPM=30 STEP=10800     // 手动顺时针旋转
M5 MOVE DIR=CCW RPM=30 STEP=10800    // 手动逆时针旋转
M5 STOP
M5 ESTOP
M5 STATUS
```

自动放衣/取衣流程默认使用PD8电磁铁：吸合和释放后各等待2秒；M5只保留手动旋转命令，不参与本次自动流程。源码中的旧夹爪备用分支仍由`CLOTH_HOLDER_USE_ELECTROMAGNET`编译开关隔离。电磁铁状态没有触点或线圈电流反馈，`MAGNET STATUS`的`FEEDBACK=NONE`不代表实际线圈电流。

常用电磁铁命令：

```text
MAGNET ON
MAGNET OFF
MAGNET STATUS
```

电磁铁吸合时会联锁新的 `ALL HOME`、`AXIS MOVE/ENC_MOVE` 和取放衣任务。自动流程故障后保持吸合并输出 `MAGNET=ON HOLD_FOR_MANUAL`，需人工 `MAGNET OFF`；`ALL ESTOP`、`AXIS ESTOP`、HardFault 和复位强制关闭电磁铁，普通 STOP 保持原状态。

### M2 RS485 绝对值编码器

M2 额外使用 BRT38-R0M1024-RT1 绝对值编码器，通过 RS485-TTL 模块接入 UART2。

```text
UART2: PA2=TXD, PA3=RXD
串口参数: 9600, 8N1
Modbus 地址: 1
分辨率: 1024 计数/圈
```

常用命令：

```text
M2 ABS_STATUS
M2 ABS_ZERO
M2 ABS_MOVE DEG=90 RPM=20
M2 ABS_MOVE DEG=90 RPM=20 DIR=CW TOL=2
M2 ROT_STATUS
M2 ROT_ZERO
M2 ROT_LIMIT_SET STEP=50000
```

`M2 ABS_ZERO` 会把 M2 当前机械位置写入编码器作为内部零点；之后 `DEG=0` 和上电自动归零都会回到这个位置。
`M2 ABS_MOVE` 使用绝对角度判断到位，并带通信失败、方向反向、卡滞检测。
当前 M2 实测方向映射为：`DIR=CW` 时编码器 `RAW` 减少，`DIR=CCW` 时编码器 `RAW` 增加。
上电后固件会延时约 2 秒自动读取 M2 绝对值编码器，并以 `RPM=20` 回到已校准的 `DEG=0` 零点；如果编码器通信失败、M2 不空闲或已在零点附近，则不会强行动作。
`M2 ROT_*` 命令用于 M2 旋转轴的开环步数基线和旋转步数限位，不会把 M2 加入 `X/Y/Z` 三轴坐标。

## HOME 回行程开关功能

HOME 功能用于让指定电机向行程开关方向运动，直到对应 EX_KEY 被触发后立即急停。

正式命令：

```text
M1 HOME_EX1 RPM=120
M2 HOME_EX2 RPM=120
M3 HOME_EX3 RPM=120
M4 HOME_EX4 RPM=120
ALL HOME RPM=120
```

行为说明：

- `M1 HOME_EX1`：M1 以 `CCW` 方向运行，直到 `EX_KEY1 / PC0` 低电平。
- `M2 HOME_EX2`：M2 以 `CCW` 方向运行，直到 `EX_KEY2 / PC1` 低电平。
- `M3 HOME_EX3`：M3 以 `CCW` 方向运行，直到 `EX_KEY3 / PC2` 低电平。
- `M4 HOME_EX4`：EX_KEY4初始为高时，M4以`CCW`向上搜索；初始为低时先`CW`向下释放，连续高20ms后再以`CCW`向上重寻，连续低20ms后完成。
- `ALL HOME`：M1/M3以CCW回行程开关，M4执行上述两段式回零，不包含M2；三轴均到位后清零EC1/EC3/EC4与XYZ。M4释放1秒或搜索60秒超时会取消整次回零且不清零，M2也不会继续启动。

到位后自动输出：

```text
OK Mx HOME_EXn_DONE EX_KEYn_LOW
```

兼容别名：

```text
M1 REV_EX1
M2 REV_EX2
M3 REV_EX3
M4 REV_EX4
ALL REV_EXKEY
ALL HOME_EXKEY
```

这些旧名称仍可使用，但建议后续统一使用 `HOME` 系列命令。

## 维护说明

- 当前工程只保留 `SmartWardrobeCode` 这一套 Keil 工程。
- 旧 `SmartWardrobe` 工程、旧 `UserFile` 架构、WK2124/SPI2 旧代码已清理。
- 新功能应优先放在 `APP/Inc` 和 `APP/Src` 中，保持业务层与 CubeMX 生成层分离。
- 修改串口命令后，应同步更新 `APP/COMMANDS.md`。
- 每次功能修改后建议重新编译并通过串口 `VER` 确认烧录版本。
