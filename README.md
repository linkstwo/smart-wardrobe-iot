# 联网智能衣柜｜STM32 运动控制 + ESP32 MQTT 网关

一套面向衣物存取机构的嵌入式工程：**STM32F407 负责多轴电机与取放衣动作，ESP32-S3 负责联网和消息转发**，电脑端工具帮助解析两者之间的串口数据。仓库同时保存了硬件图纸和机构调试资料。

原仓库名为 `Sum-2-M2CanTurn`，现名为 `smart-wardrobe-iot`。这里包含 STM32 控制程序与 ESP32 网关；远程服务器本身的完整应用代码未包含在当前仓库中。

## 工作原理

```text
远程服务器 / 上位机
        ⇅ Wi-Fi + MQTT，JSON 消息
ESP32-S3 联网网关
        ⇅ UART，A5 CMD LEN DATA CRC 5A 二进制帧
STM32F407 机构控制器
        ⇅ 电机驱动、编码器、限位、测距与执行器
回零 → 定位 / 扫描 → 取衣或放衣 → 状态回传
```

服务器发送存衣、取衣、回零或状态查询命令；ESP32 将消息转换为串口帧交给 STM32。STM32 根据指令执行机构动作，结合编码器、限位与测距反馈处理流程，再由 ESP32 回传操作结果或故障信息。

串口帧包含帧头、命令、长度、数据、异或校验和帧尾。详细定义与支持范围见 [通信协议](server_esp/协议.md)。

## 从哪里开始

1. **先理解链路**：读 [网关说明](server_esp/docs/README.md) 和 [通信协议](server_esp/协议.md)。
2. **再看机构控制**：用 Keil MDK 打开 [SmartWardrobeCode.uvprojx](SmartWardrobe/MDK-ARM/SmartWardrobeCode.uvprojx)，结合 [程序介绍](SmartWardrobe/程序介绍.md) 阅读。
3. **配置联网网关**：在 ESP-IDF 环境中进入 `server_esp/`，按网关说明配置目标芯片、Wi-Fi、MQTT 和串口参数，再构建与烧录。网关说明标注 ESP-IDF v5.5、ESP32-S3。
4. **查看通信内容**：按 [串口解析工具说明](串口协议解析工具/代码/README.md) 解析 HEX 或监听串口，确认命令与响应含义。

当前文档规定：存衣只支持 `position=1`；取衣支持 `position=1..255`，表示从 X 原点扫描到的第 N 块三级定位板。**通信参数的取值范围不等于机构已经具备相同数量的可用衣位。**

## 与单独 STM32 仓库的关系

[智能衣柜 STM32 控制器](https://github.com/linkstwo/stm32-smart-wardrobe-controller) 侧重下位机运动控制。本仓库把另一份 STM32 代码、ESP32 联网网关、协议和工具放在一起便于联调；两边并非自动同步，使用时应分别核对代码版本和命令定义。

## 当前状态

本仓库提供源码、工程与调试资料，供继续开发和联调。本次首页整理核对了文件、协议和网关应用实现，**未重新编译、烧录，也未验证 MQTT 实际收发或衣柜机械动作**。调试记录中的具体步数、编码器值和动作顺序属于对应机构配置，应在匹配硬件上重新确认。
