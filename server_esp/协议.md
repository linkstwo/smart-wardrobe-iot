# 智能衣柜通信协议

## 1. 系统架构

```
┌──────────┐    MQTT     ┌──────────┐    UART     ┌──────────┐
│  服务器   │ ◄─────────► │   ESP    │ ◄─────────► │ STM主控  │
│ (上位机)  │            │ (ESP32)  │            │ (STM32)  │
└──────────┘            └──────────┘            └──────────┘
```

| 链路 | 方式 | 详情 |
|------|------|------|
| STM ↔ ESP | UART 串口 | 115200-8N1，二进制帧协议 |
| ESP ↔ 服务器 | MQTT | JSON 载荷，QoS 1 |

---

## 2. 角色与命令

### 2.1 下行命令（服务器 → ESP → STM）

| 命令 | 命令码 | 说明 |
|------|--------|------|
| 存衣服 | `0x10` | 存入衣物，附带位置信息 |
| 取衣服 | `0x11` | 取出衣物，附带位置信息 |
| 复位回零 | `0x12` | 执行 ALL HOME 回零（无数据段） |
| 读状态 | `0x20` | 查询设备状态（无数据段） |

### 2.2 上行响应（STM → ESP → 服务器）

| 响应 | 命令码 | 说明 |
|------|--------|------|
| 操作成功 | `0x90` | 存取操作正确完成 |
| 故障异常 | `0x91` | 发生故障，附带故障码 |

---

## 3. UART 串口帧协议（STM ↔ ESP）

### 3.1 帧结构

```
┌──────┬──────┬──────┬─────────────┬──────┬──────┐
│ SOF  │ CMD  │ LEN  │    DATA     │ CRC  │ EOF  │
│ 1B   │ 1B   │ 1B   │    N 字节    │ 1B   │ 1B   │
└──────┴──────┴──────┴─────────────┴──────┴──────┘
```

| 字段 | 长度 | 说明 |
|------|------|------|
| SOF | 1 字节 | 帧头，固定 `0xA5` |
| CMD | 1 字节 | 命令码 / 响应码 |
| LEN | 1 字节 | DATA 段长度，范围 0 ~ 128 |
| DATA | N 字节 | 数据载荷，长度由 LEN 指定 |
| CRC | 1 字节 | 校验和，CMD + LEN + DATA 各字节异或 |
| EOF | 1 字节 | 帧尾，固定 `0x5A` |

> 帧总长度范围：5 ~ 133 字节

### 3.2 校验示例

```
CMD=0x10, LEN=0x01, DATA[0]=0x03
CRC = 0x10 ^ 0x01 ^ 0x03 = 0x12
完整帧: A5 10 01 03 12 5A
```

## 4. 串口命令定义

### 4.1 存衣服 `0x10`

> **ESP → STM**

| 字段 | 值 | 说明 |
|------|-----|------|
| CMD | `0x10` | 存衣服命令 |
| LEN | `0x01` | |
| DATA[0] | 位置编号 | 当前存衣只支持 `position=1` |

**示例**：存入 1 号格 — `A5 10 01 01 10 5A`

---

### 4.2 取衣服 `0x11`

> **ESP → STM**

| 字段 | 值 | 说明 |
|------|-----|------|
| CMD | `0x11` | 取衣服命令 |
| LEN | `0x01` | |
| DATA[0] | 位置编号 | 有效范围 `1 ~ 255`，表示从 X 原点扫描到的第 N 块三级定位板 |

**示例**：取出 1 号格 — `A5 11 01 01 11 5A`

---

### 4.2.1 复位回零 `0x12`

> **ESP → STM**

| 字段 | 值 | 说明 |
|------|-----|------|
| CMD | `0x12` | 复位回零命令 |
| LEN | `0x00` | 无数据段 |

**示例**：`A5 12 00 12 5A`

---

### 4.3 读状态 `0x20`

> **ESP → STM**

| 字段 | 值 | 说明 |
|------|-----|------|
| CMD | `0x20` | 读状态命令 |
| LEN | `0x00` | 无数据段 |

**示例**：`A5 20 00 20 5A`

---

### 4.4 操作成功 `0x90`

> **STM → ESP**

| 字段 | 值 | 说明 |
|------|-----|------|
| CMD | `0x90` | 操作成功 |
| LEN | `0x01` | |
| DATA[0] | 位置编号 | 确认当前操作对应的位置 |

**示例**：1 号格操作成功 — `A5 90 01 01 90 5A`

---

### 4.5 故障异常 `0x91`

> **STM → ESP**

| 字段 | 值 | 说明 |
|------|-----|------|
| CMD | `0x91` | 故障异常 |
| LEN | `0x02` | |
| DATA[0] | 故障码 | 见下表 |
| DATA[1] | 位置编号 | 相关位置（若无则为 `0xFF`） |

**故障码定义**：

| 故障码 | 含义 |
|--------|------|
| `0x01` | 电机过流 |
| `0x02` | 电机堵转 |
| `0x03` | 限位开关异常 |
| `0x04` | 传感器故障 |
| `0x05` | 通信超时 |
| `0x06` | EEPROM 读写错误 |
| `0x07` | 格位被占用（存衣时） |
| `0x08` | 格位为空（取衣时） |
| `0xFF` | 未知故障 |

**示例**：3 号格电机堵转 — `A5 91 02 02 03 92 5A`

---

### 4.6 状态上报 `0xA0`

> **STM → ESP**（响应读状态 `0x20`）

| 字段 | 值 | 说明 |
|------|-----|------|
| CMD | `0xA0` | 状态上报 |
| LEN | `0x06` | |
| DATA[0:1] | 衣服数量 | uint16，大端序 |
| DATA[2:3] | 运行天数 | uint16，大端序 |
| DATA[4] | 运行小时 | 0 ~ 23 |
| DATA[5] | 运行分钟 | 0 ~ 59 |

**示例**：衣柜有 12 件衣服，运行 3 天 8 小时 30 分 — `A5 A0 06 00 0C 00 03 08 1E BF 5A`

## 5. MQTT 协议（ESP ↔ 服务器）

### 5.1 主题定义

| 方向 | 主题 | QoS |
|------|------|-----|
| 服务器 → ESP | `/k1vtgAzED8C/7Rzu9Cy7Ze6Yhe1YcMjQ/user/wardrobe` | 1 |
| ESP → 服务器 | `/k1vtgAzED8C/7Rzu9Cy7Ze6Yhe1YcMjQ/user/wardrobe` | 1 |

### 5.2 命令载荷（服务器 → ESP）

所有命令为 JSON 格式。

#### 存衣服

```json
{
  "cmd": 16,
  "position": 1
}
```

#### 取衣服

```json
{
  "cmd": 17,
  "position": 1
}
```

#### 读状态

```json
{
  "cmd": 32
}
```

| cmd | 含义 |
|-----|------|
| 16 | 存衣服 |
| 17 | 取衣服 |
| 18 | 复位回零 |
| 32 | 读状态 |

---

### 5.3 响应载荷（ESP → 服务器）

#### 操作成功

```json
{
  "status": 144,
  "action": 16,
  "position": 3,
  "timestamp": 1716624000
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| status | int | 固定 `144`（0x90） |
| action | int | `16` 存衣服 / `17` 取衣服 |
| position | int | 操作的位置编号 |
| timestamp | int | Unix 时间戳（秒） |

#### 故障异常

```json
{
  "status": 145,
  "code": 2,
  "msg": "motor_stall",
  "position": 3,
  "timestamp": 1716624000
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| status | int | 固定 `145`（0x91） |
| code | int | 故障码（同串口定义） |
| msg | string | 故障描述 |
| position | int | 相关位置（无则为 `-1`） |
| timestamp | int | Unix 时间戳（秒） |

#### 状态上报

```json
{
  "status": 160,
  "clothing_count": 12,
  "uptime_days": 3,
  "uptime_hours": 8,
  "uptime_minutes": 30,
  "timestamp": 1716624000
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| status | int | 固定 `160`（0xA0） |
| clothing_count | int | 当前衣柜中衣物数量 |
| uptime_days | int | 系统运行天数 |
| uptime_hours | int | 小时（0~23） |
| uptime_minutes | int | 分钟（0~59） |
| timestamp | int | Unix 时间戳（秒） |

## 6. 通信流程

### 6.1 存衣服流程

```
服务器                  ESP                   STM
  │                      │                      │
  │──MQTT store pos=3──►│                      │
  │                      │──UART 0x10 pos=3───►│
  │                      │                      ├─ 执行存衣动作
  │                      │◄──UART 0x90 pos=3───│  (成功)
  │◄──MQTT success──────│                      │
  │                      │                      │
```

异常时 STM 回复 `0x91` 带故障码，ESP 通过 MQTT 上报 `fault`。

### 6.2 取衣服流程

同存衣流程，命令码替换为 `0x11`。

### 6.3 读状态流程

```
服务器                  ESP                   STM
  │                      │                      │
  │──MQTT status────────►│                      │
  │                      │──UART 0x20──────────►│
  │                      │◄──UART 0xA0 state────│
  │◄──MQTT state────────│                      │
  │                      │                      │
```

## 7. 超时与重试

| 参数 | 值 | 说明 |
|------|-----|------|
| 串口应答超时 | 3000 ms | STM 须在此时间内应答 |
| 串口最大重试 | 3 次 | 超时后 ESP 重发命令帧 |
| MQTT 命令超时 | 5000 ms | 服务器等待 ESP 响应的最长时间 |
| Keep Alive | 60 s | MQTT 心跳间隔 |

超时 3 次无应答，ESP 上报服务器故障（code=5 通信超时）。

ESP32 对存衣只放行 `position=1`；对取衣放行 `position=1..255` 并原样转发，不再把 `position=5` 映射到 1 号位。
